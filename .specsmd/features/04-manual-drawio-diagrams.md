# Manual Draw.io Diagrams

Users can manually create diagrams using embedded Draw.io.

Flow:

User
----

Open project
------------

Create diagram
--------------

Open Draw.io editor
-------------------

Draw manually
-------------

Save
----

Frontend sends Draw.io XML to backend
-------------------------------------

Backend creates diagram version

Manual diagram source:

diagrams.source = manual

Diagram XML storage:

diagram_versions.drawio_xml
