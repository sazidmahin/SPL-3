# Workspaces

A workspace is the tenant boundary.

Types:

- personal
- organization

Every user has one personal workspace.

Users can create organization workspaces.

Users can switch between workspaces in the frontend.

Workspace members have roles:

- owner
- admin
- member
- viewer

Personal workspace:

- max one active member
- owner is the user

Organization workspace:

- can have multiple members
- member count limited by subscription plan
