# Product Vision

The system is a web-based SRS and diagram generation platform.

Users can manually create and edit diagrams using an integrated Draw.io editor.

AI-based SRS generation requires a paid subscription.

The platform supports both:

- Individual users with personal subscriptions
- Organization users with organization-level subscriptions

The backend will use FastAPI.
The frontend will use React, TypeScript, and Yarn.
The database will use workspace-level tenant isolation.
