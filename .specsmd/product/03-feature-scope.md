# Feature Scope

## MVP Features

1. User registration and login
2. Personal workspace creation after registration
3. Organization workspace creation
4. Workspace member management
5. Project creation
6. Manual Draw.io diagram editor
7. Save Draw.io XML
8. Diagram versioning
9. Subscription plan model
10. Workspace-level subscription check
11. AI SRS generation
12. Requirement extraction and classification
13. Class diagram generation
14. Open generated class diagram in Draw.io
15. Export generated artifacts if plan allows

## Later Features

1. Use case diagram generation
2. Sequence diagram generation
3. ER diagram generation
4. Activity diagram generation
5. State diagram generation
6. File upload for requirements
7. Meeting transcript support
8. Team comments/review workflow
9. Advanced billing portal
10. Admin analytics
